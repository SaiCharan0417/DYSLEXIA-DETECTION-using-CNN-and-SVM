About DyslexiaLens

What the website is designed to do.

THE IDEA

Make handwriting analysis easier to understand.

DyslexiaLens is a project prototype for handwriting-based dyslexia screening. The interface is built to make the machine-learning pipeline understandable: a handwriting image can be uploaded, analyzed by the backend model, and returned as a structured report.

Depending on the final backend, the pipeline may use image preprocessing, MobileNetV2/CNN-based feature extraction, a feature vector, SVM classification, and Grad-CAM-style visual explanation.

01

Upload

Select a handwriting sample from your device.

02

Analyze

Send the image to your FastAPI + ML pipeline.

03

Report

Display prediction, confidence and supporting visual details.

Important

This is a preliminary screening prototype. It should not be presented as a medical diagnosis or as a replacement for a qualified assessment.

FEATURE SUMMARY

What the model looked at

The supplied backend preprocesses the image to 32×32 grayscale, extracts a 128-dimensional feature vector with the saved CNN extractor, then sends that vector through StandardScaler + LinearSVC. The API does not return human-readable measurements such as slant or spacing.
